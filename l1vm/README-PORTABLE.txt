L1VM PORTABLE
=============
The "run-prog.sh" script can be called with a program name.
It sets the L1VM paths to the directory it is in.
So the portable L1VM in it can be run.

To set this directory as the L1VM root: run the "set-path.sh" script.

Copy the binaries into the "bin" directory.
Now you can run the programs.

Linux
=====
You can run "make-portable.sh" to copy all program and module dependencies into the "bin" directory. Then the programs should work on any system.
